# Sneaker Resale Business Analysis: Defile de Mode (2022–2024)

Profitability, channel efficiency, and dead stock analysis of a personal sneaker resale business using real transaction data.

## Tools & Skills
Python · Pandas · Matplotlib · Data Cleaning · Exploratory Data Analysis

## Key Findings
- **Alias outperforms Kick Avenue** by 6.5 margin points at comparable volume (~300 transactions each)
- **Adidas delivers 35.1% margin** vs Nike's 22.8%, despite Nike having 5× more transactions
- **Rp 288.7M capital frozen** in 159 unsold items — all stagnant for over 1 year as of mid-2026
- 2024 purchasing decisions resulted in the largest dead stock concentration (Rp 149M, 92 units)
